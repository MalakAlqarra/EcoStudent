 Portal EcoStudent 

**Portal EcoStudent** is a sustainable, user-friendly web application designed to digitize academic activities. This platform allows students to manage their university life by registering for courses, viewing weekly schedules, and calculating their GPA in a streamlined digital environment.



##  Features (Must-Have)
- **User Authentication:** Simulated login system for students and administrators.
- **Course Search:** Easily search for courses by name or code.
- **Online Registration:** Add and drop courses dynamically with real-time updates.
- **Visual Class Schedule:** A weekly calendar view that reflects the student's registered courses.
- **GPA Calculator:** Automatic calculation of the Grade Point Average based on credit hours and entered marks.

## 🛠️ Tech Stack
This project is built using pure Frontend technologies to ensure high performance and smooth user experience:
- **HTML5:** Semantic structure for web pages.
- **CSS3:** Custom styling with a focus on "Eco-friendly" UI/UX (Forest Green theme).
- **JavaScript (ES6+):** Functional logic, DOM manipulation, and data handling.
- **Local Storage:** Used for persistent data storage within the browser (simulating a database).
